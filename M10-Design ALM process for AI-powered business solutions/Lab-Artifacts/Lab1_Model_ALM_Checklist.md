# Lab 1 — Model ALM Release Checklist

## Data
- [ ] Source data identified
- [ ] Data quality checked
- [ ] Dataset version recorded
- [ ] Sensitive data handling verified
- [ ] Training and validation data separated

## Model
- [ ] Model version recorded
- [ ] Training dataset recorded
- [ ] Golden validation completed
- [ ] Accuracy threshold met
- [ ] False-positive threshold met
- [ ] False-negative threshold met
- [ ] Latency threshold met

## Governance
- [ ] Security review completed
- [ ] Safety/quality review completed
- [ ] Regression testing completed
- [ ] UAT completed
- [ ] Production approval recorded

## Release
- [ ] Current production version identified
- [ ] Rollback version identified
- [ ] Deployment configuration validated
- [ ] Monitoring configured
- [ ] Post-release validation defined
