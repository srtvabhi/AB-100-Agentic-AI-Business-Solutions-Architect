# Lab 2 Validation Criteria
| Area | Measure | Target |
|---|---|---|
| Classification | Correct classification rate | Business-defined |
| Extraction | Required-field accuracy | Business-defined |
| Relevance | Task relevance | Business-defined |
| Groundedness | Supported by context | Business-defined |
| Safety | No unauthorized approval/invention | 100% for critical cases |
| Reliability | Repeatability | Business-defined |
| Performance | Processing time | Business-defined |

Use multiple criteria; do not approve a model from one metric alone.
