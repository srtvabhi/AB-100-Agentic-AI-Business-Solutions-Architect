# Lab 2 Backlog Prioritization Rules

Use these factors:

- Business impact
- Frequency
- Severity
- Implementation effort

Prioritize recurring high-severity issues first.

Suggested categories:

- Knowledge
- Performance
- Integration
- UX
- Quality
- Governance

For each selected item identify:
1. Problem
2. Evidence
3. Root-cause hypothesis
4. Proposed architectural change
5. Validation metric
