# Lab 3 Tuning Test Scenarios

Run the same scenarios before and after tuning:

1. Summarize a customer with 5 relevant records.
2. Summarize a customer with 20 records.
3. Summarize a customer with missing CRM data.
4. Summarize a customer with conflicting knowledge.
5. Run a summary that requires an external API call.

Capture:
- latency
- model calls
- token usage
- retrieval items
- workflow time
- API time
- task completion
- user satisfaction/quality result
