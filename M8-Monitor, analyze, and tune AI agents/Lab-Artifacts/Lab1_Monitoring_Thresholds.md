# Lab 1 Monitoring Thresholds

| Metric | Warning | Critical |
|---|---:|---:|
| Average latency | > 3 sec | > 4 sec |
| Error rate | > 2% | > 3% |
| Abandonment rate | > 8% | > 12% |
| Escalation rate | > 8% | > 12% |
| Successful task rate | < 90% | < 85% |

Use the thresholds to identify dates requiring investigation.
