# Lab 1 Supplier Portal Task

## Scenario

Contoso Manufacturing uses a legacy supplier portal that does not provide a supported API or connector.

## Task

Use the portal to locate the invoice status for the supplier below.

| Field | Value |
|---|---|
| Supplier ID | SUP-1007 |
| Supplier | Alpine Industrial Parts |
| Invoice | INV-2026-0418 |
| Purchase Order | PO-450017 |
| Expected Status | Pending Review |

## Required Result

Record:

1. Supplier name
2. Invoice number
3. Current status
4. Portal date shown
5. Whether the result was successfully validated

## Safety Rules

- Do not approve or reject the invoice.
- Do not change supplier data.
- Do not submit financial transactions.
- Stop if the portal displays unexpected content.
- Escalate if the invoice cannot be found or the result cannot be validated.
