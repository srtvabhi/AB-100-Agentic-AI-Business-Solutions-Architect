# Customer Case Summary Prompt

## Goal
Summarize a customer case for a service representative.

## Context
Use the case fields supplied by the agent.

## Instructions
- Identify the issue.
- State the current status.
- Identify the assigned team.
- Keep the summary concise.
- Do not add facts that are not present in the case data.

## Output Format
Issue:
Status:
Assigned Team:
Recommended Next Step:
