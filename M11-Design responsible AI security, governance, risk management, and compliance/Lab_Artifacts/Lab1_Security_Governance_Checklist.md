# Lab 1 — Security and Governance Checklist

## Identity
- [ ] User identity is established.
- [ ] Agent identity is defined where applicable.
- [ ] Authentication is required.
- [ ] Authorization is evaluated before data access.

## Least Privilege
- [ ] Customer data access is limited.
- [ ] Sensitive data requires appropriate permissions.
- [ ] Agent tools are explicitly allowed.
- [ ] Production modification is restricted.

## High-Impact Actions
- [ ] Financial actions are identified.
- [ ] Destructive actions are identified.
- [ ] Irreversible actions are identified.
- [ ] Approval requirements are defined.
- [ ] Business rules are validated before execution.

## Governance
- [ ] Agent risk is classified.
- [ ] Agent owner is assigned.
- [ ] Approved data sources are documented.
- [ ] Approved tools are documented.
- [ ] Required reviews are defined.

## Monitoring and Audit
- [ ] Agent activity is monitored.
- [ ] Sensitive actions are traceable.
- [ ] Configuration changes are recorded.
- [ ] Production releases are controlled.
